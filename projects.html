MP3 Metadata Fixer

Why was this created?

Many music collections contain missing, incorrect, or inconsistent metadata. Fixing every file manually can become a long and frustrating process.

MP3 Metadata Fixer was created to make cleaning and repairing MP3 metadata easier, faster, and more accessible.

Development idea:
The goal was to create a simple Windows tool that helps users keep their personal music libraries organized without complicated software.

File Name Cleaner

Why was this created?

When collecting files from different sources, especially downloaded files, filenames can quickly become messy. Files often contain unnecessary information, strange spaces, underscores, numbers, or extra details that make organizing a collection difficult.

The same problem appears with personal pictures from cameras, where filenames are often automatic numbers that do not give much information about the actual content.

Development idea:
File Name Cleaner was created to make it possible to quickly rename many files at once, helping users create cleaner and more organized collections.

The project also includes improvements from earlier tools, such as extension handling features that were originally developed separately in Reuclu.exe.

InGameRUN

Why was this created?

While playing games, many players keep their left hand in the same position for a long time, using keys like W and Shift for movement and running. This can become uncomfortable, especially during longer gaming sessions.

Some games require players to keep running or moving constantly, making it difficult to quickly step away for a short break, like getting a drink.

Development idea:
InGameRUN was created to make gaming sessions more comfortable by providing a simple way to manage running actions without forcing players to hold the same keys continuously. The goal was to create a small utility that improves comfort while keeping the focus on the game experience.

Video Conference

Why was this created?

Reuclu.exe

Why was this created?

Some files can have problems when their file extensions use unexpected uppercase or lowercase letters. Certain programs, browsers, or devices may not recognize files correctly when the extension format is not what they expect.

Reuclu.exe was created as a small utility to quickly change file extensions between uppercase and lowercase, helping improve compatibility with different software.

Development idea:
The project started as a simple standalone tool for solving extension-related problems. Later, this functionality became part of the larger File Name Cleaner concept, where file organization and cleanup could be handled in one place.

v2.0

Clean Hard Drive

Why was this created?

Clean Hard Drive originally started as a feature inside the Movie Index, Music Index, and Image Index applications. These programs created their own collection data, and there was a need for a simple way to remove unwanted files and clean up stored data.

After seeing that this function could also be useful outside of the index applications, the idea developed into a standalone tool for general computer cleanup.

Development idea:
The goal was to create a safer and more flexible cleaning utility where users can review what they want to remove, create backups when needed, and manage unnecessary files more easily.

Instead of automatically deleting everything, Clean Hard Drive focuses on giving users more control over keeping their computer organized and maintaining free storage space.

Movie Index

Why was this created?

Having a large movie collection can become difficult to manage. Friends and family often asked for movies, which meant searching through folders, preparing USB sticks, and manually finding the right files again and again.

Movie Index was created to solve this problem by creating a simple catalog of the movie collection. Instead of searching through folders, users can browse the available movies, view information, and find what they are looking for more easily.

Development idea:
The idea was to create a private media library where people connected to the same network could access the collection, browse available movies, and choose what they wanted without needing someone else to prepare everything manually.

The project was designed with private sharing in mind, allowing personal collections to be organized and accessed more comfortably inside a home network or private connection.

File Finder Tool

Why was this created?

Finding files on a computer can sometimes be frustrating. Many search tools are limited by specific locations, exact names, or simple search options, making it difficult to find something when you only remember a small part of the information.

File Finder Tool was created to make searching more flexible. Users can search for files using only a few letters, a file extension, or other available information, allowing them to find what they need faster.

Development idea:
The goal was to create a powerful but simple file search utility that gives users more control over finding their own data.

Instead of remembering exactly where a file is stored, the application helps users discover files quickly and efficiently across their computer.

Hotspot Toggle

Why is this being created?

Windows already includes a mobile hotspot feature, but enabling it requires several manual steps every time the computer starts. Since I use my computer's hotspot every day for my mobile devices, repeating the same process became unnecessary and frustrating.

JustLive

Why is this being created?

Many zombie survival games follow the same formula. While playing them, I often felt that something important was missing. Survival should be about adapting to an evolving world, not simply repeating the same mechanics found in many existing games.

JustLive began with the idea of creating a different kind of survival experience, where player choices, exploration, and unique gameplay systems create stories that feel more natural and personal.

The goal is to build a multiplayer zombie survival game that offers fresh ideas while keeping the focus on exploration, cooperation, and player-driven experiences. Instead of copying existing games, JustLive aims to introduce new mechanics that make surviving feel challenging, rewarding, and different every time you play.
